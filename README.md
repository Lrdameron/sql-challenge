# Employee Database Analysis

## Overview
This project focuses on designing and analyzing an employee database for Pewlett Hackard, a fictional company. The database contains historical employee records, including departments, job titles, salaries, and managerial roles.

## Features
### Database Design
- Created an **Entity Relationship Diagram (ERD)** to model the database structure.
- Defined **six relational tables** with primary keys and foreign keys:
  - Employees
  - Departments
  - Titles
  - Salaries
  - Department Employees
  - Department Managers

### Data Engineering
- Created the database schema and tables using PostgreSQL.
- Imported historical employee data from CSV files using DBeaver.

### Data Analysis
- Wrote SQL queries to retrieve insights, including:
  - Employee details and salaries
  - Employees hired in a specific year
  - Department managers and their employees
  - Employees in specific departments
  - Most common last names among employees

## Dependencies
This project requires the following tools:
- PostgreSQL
- DBeaver
- pgAdmin
- GitHub

## Results & Insights
- Successfully modeled and populated an employee database.
- Identified department managers and their respective employees.
- Analyzed hiring trends and the most common employee last names.
- Queried employees by department and job title for detailed insights.
